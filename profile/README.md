# AI in Research @ CREST

**AI in Research — 2026-2027 cycle**: short, filmed trainings for CREST members on using AI tools — Claude Code — in research: getting started, concrete workflows, limits and good practices.

- 🌐 **Website** — trainings (recordings & slides), key references, blog: <https://crest-science.github.io>
- 💬 **Discussions** — ask questions, share uses, propose training topics: <https://github.com/orgs/crest-science/discussions>
- ✍️ **Contribute** — <https://crest-science.github.io/contribute.html>

Organizers: Nicolas Brosse, Émilien Schultz.
